Data Flow (How It Works)

  1. 1 User enters unique HUID from jewellery into the mobile/web UI app interface.
  2. 2 Frontend application packages secure network request payload to send to database.
  3. 3 App establishes real-time encrypted handshake with the **Central BIS Database**.
  4. 4 Retrieves secure, unalterable authentic hallmarking details registered by authorities.
